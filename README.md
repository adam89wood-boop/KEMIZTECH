# KEMIZTECH

Supporting content for [kemiztech.com.au](https://kemiztech.com.au), Adam Wood's apps
and creative-tools portfolio.

- `content/site-copy.md` — source-of-truth copy for the live site (built with
  VentraIP's VIPsites builder, which has no exportable source, so this is the only
  version-controlled record of what's published).
- `site/index.html` — a standalone, self-contained HTML portfolio page covering
  OTGExplorer, OtgxDesktop, and Salvage, with a Google AdSense auto-ads script wired in.
  Built as an alternative for a host that supports custom script injection, since
  VIPsites does not.
