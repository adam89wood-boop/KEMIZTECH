/dev/otg0 — android

OTGExplorer

A file browser for the drives your phone normally can't see into properly.

Plug in a USB-OTG drive, an SD card reader, or a camera, and browse it like local storage — including RAW photo formats most file managers choke on. Built for photographers, field techs, and anyone who's tired of their phone pretending external storage doesn't exist.

  • Native USB-OTG and SD card browsing
  • RAW photo format support (CR2, ARW, NEF and friends)
  • No desktop required — works straight off the device
  • Lightweight: a browser, not a bloated suite

OtgxDesktop

A fast Windows file browser that doesn't give up when a file goes missing.

Browse drives normally in the Drives tab, run a quick signature-carve on a suspect file or image in Recover, or step up to Deep Recovery for forensic-grade undelete when it actually matters. OtgxDesktop only asks for elevated access when Deep Recovery needs it — not for every click.

  • Drives — a clean everyday file browser
  • Recover — quick pure signature carving on a file or disk image
  • Deep Recovery — forensic-grade undelete, powered by the Salvage engine
  • Runs at standard privilege; elevates only for Deep Recovery

salvage://core — windows, rust

Salvage

The forensic engine underneath. NTFS, FAT32, exFAT — raw and unflinching.

Salvage reads volumes the way a forensic examiner would: direct $MFT parsing on NTFS, directory-tree undelete on FAT32 and exFAT, raw Windows volume access, and byte-accurate signature carving when there's no filesystem left to trust. A native Rust core keeps it fast; a CLI and a WinUI3 app sit on top for whichever way you need to work.

  • Native Rust core — no managed-runtime overhead on the hot path
  • NTFS $MFT parsing with MACB forensic timeline reconstruction
  • FAT32 / exFAT / FAT12-16 directory-tree undelete
  • Marker-aware signature carving — JPEGs recover whole, not truncated
  • Headless CLI for scripted recovery, plus a full desktop app
