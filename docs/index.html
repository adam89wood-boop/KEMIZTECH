windows, rust — forensic recovery

Salvage

Forensic recovery engine

Salvage reads volumes the way a forensic examiner would: direct $MFT parsing on NTFS, directory-tree undelete on FAT32 and exFAT, raw Windows volume access, and byte-accurate signature carving when there's no filesystem left to trust. A native Rust core keeps it fast, with both a CLI and a desktop app on top.

  • Native Rust core for fast, low-overhead recovery
  • NTFS $MFT parsing with forensic timeline reconstruction
  • FAT32, exFAT, and FAT12-16 directory-tree undelete
  • Marker-aware signature carving so recovered files aren't truncated
