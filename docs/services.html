Salvage

Salvage is a local data-recovery and file-inspection product made up of:

  • A Windows desktop app (Salvage 5.0.0), a WinUI 3 application with MSI installer and portable ZIP.
  • An Android application source project (version 4.0.1, Android 10+ target).
  • A shared native Rust recovery engine and command-line utility.

The Windows app supports recovery and inspection workflows across NTFS, FAT/FAT32 and exFAT media and disk images. Features include deleted-file recovery, file-signature carving, free-space/full-surface scan modes, pause/continue workflows, browsing, previews, file inspection, integrity checks, recovery passports and controlled restore destinations. The Inspect area includes file and disk-image browsing/carving, file metadata and format analysis, photo/RAW preview support, hex/strings/histogram views and media playback subject to installed codecs.

The source release notes document practical limits: live-drive recovery may require administrator access; source inspection is read-only; integrity labels are structural checks and do not guarantee completeness; recovery success depends on filesystem, device and data condition. Android is currently at v4.0.1 while Windows is v5.0.0.
